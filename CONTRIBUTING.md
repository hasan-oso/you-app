# Contributing

Thank you for your interest in **YOU — Smart Health Companion**.

This repository is published under a **proprietary license** (see [LICENSE](LICENSE)) and external code contributions are not currently accepted. The codebase is shared publicly for portfolio review, educational reference, and transparency.

That said, the following kinds of input are very welcome:

## 🐛 Bug Reports

If you find a bug while using the live app:

1. Open an issue with the **bug** label.
2. Include device model, OS version, app version, and steps to reproduce.
3. Attach screenshots or screen recordings if relevant.
4. **Do not** include personal data, screenshots of your account, or screenshots that contain other users' data.

## 💡 Feature Suggestions

Have an idea? Open an issue with the **enhancement** label and describe:

- The problem the feature would solve
- The user experience you'd expect
- Any references or examples from other apps

We can't promise every suggestion will be implemented, but every well-described idea will be read and considered.

## 🌐 Translation Improvements

If you spot a typo, mistranslation, or unnatural phrasing in **Arabic**, **Turkish**, or **English**:

- Open an issue with the **localization** label.
- Quote the exact string and propose the corrected wording.

Translations live in [`lib/core/localization/`](lib/core/localization/).

## 🔒 Security Issues

**Do not open a public issue** for security problems. See [SECURITY.md](SECURITY.md) for the private reporting process.

## 📜 Code Contributions

Direct code contributions (pull requests) are **not accepted** under the current proprietary license. If you have a strong interest in collaborating, please reach out via the contact information on the [@hasanoso151](https://github.com/hasanoso151) GitHub profile to discuss a licensing arrangement.

## Code of Conduct

By interacting with this repository, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md). In short: be kind, be constructive, and assume good faith.
